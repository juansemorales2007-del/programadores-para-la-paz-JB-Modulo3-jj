Pregunta 7:
¿Qué sucede cuando consultas los reportes?

Cuando se realiza una petición GET a la ruta /reportes, el servidor devuelve todos los reportes que han sido almacenados en el array reportes.

Cada vez que se envía un nuevo reporte mediante una petición POST, este se agrega al array junto con un identificador único. Posteriormente, al consultar nuevamente la ruta GET, se muestra la lista completa de reportes registrados.

Ejemplo de respuesta:

[
  {
    "id": 1,
    "tipo": "Infraestructura",
    "descripcion": "Daño en alumbrado público"
  },
  {
    "id": 2,
    "tipo": "Ambiente",
    "descripcion": "Acumulación de residuos en una zona comunitaria"
  }
]

Los datos permanecen disponibles mientras el servidor esté en ejecución. Si el servidor se detiene o reinicia, los reportes se eliminan porque están almacenados únicamente en memoria y no en una base de datos.
