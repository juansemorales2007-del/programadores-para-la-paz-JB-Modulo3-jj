server.js
const express = require('express');
const app = express();

app.use(express.json());

let reportes = [];

app.get('/reportes', (req, res) => {
  res.json(reportes);
});

app.post('/reportes', (req, res) => {

  const reporte = {
    id: reportes.length + 1,
    tipo: req.body.tipo,
    descripcion: req.body.descripcion
  };

  reportes.push(reporte);

  res.json({
    mensaje: "Reporte registrado",
    reporte: reporte
  });

});

app.listen(3000, () => {
  console.log('Servidor ejecutándose en puerto 3000');
});
prueba-reportes.txt
Al consultar la ruta GET /reportes, el servidor devuelve todos los reportes almacenados en el arreglo llamado reportes.

Cuando se envía información mediante la ruta POST /reportes, los datos son guardados temporalmente en memoria y se les asigna un identificador automático.

Después de registrar uno o varios reportes, al realizar una petición GET se obtiene una lista en formato JSON con todos los reportes registrados.

Si el servidor se detiene o reinicia, la información almacenada se pierde porque los datos no se guardan en una base de datos, sino únicamente en memoria.

reflexion-semana7.txt
Es importante que las comunidades puedan registrar y consultar reportes o incidencias en una plataforma tecnológica porque facilita la comunicación entre los ciudadanos y las entidades responsables. Estas herramientas permiten organizar la información de manera rápida y eficiente. Además, ayudan a identificar problemas frecuentes en una comunidad y darles seguimiento. Los reportes pueden contribuir a mejorar la seguridad, el medio ambiente y la infraestructura local. También promueven la participación ciudadana y el trabajo colaborativo. Una plataforma tecnológica permite acceder a la información desde diferentes lugares y en cualquier momento. Esto mejora la transparencia en la gestión de los problemas reportados. Asimismo, facilita la toma de decisiones basada en información real. Por estas razones, los sistemas de reportes son una herramienta valiosa para el desarrollo y bienestar de las comunidades.

prueba-reportes.txt
Al consultar la ruta GET /reportes, el servidor devuelve todos los reportes almacenados en el arreglo reportes.

Cuando se envía información mediante la ruta POST /reportes, el servidor recibe los datos en formato JSON, crea un nuevo objeto con un identificador único y lo almacena en memoria dentro del array reportes.

Después de registrar varios reportes, la ruta GET /reportes permite visualizar la lista completa de reportes registrados.

Por ejemplo, después de registrar dos reportes, la respuesta puede ser:

[
  {
    "id": 1,
    "tipo": "Infraestructura",
    "descripcion": "Daño en alumbrado público"
  },
  {
    "id": 2,
    "tipo": "Ambiente",
    "descripcion": "Acumulación de residuos en una zona comunitaria"
  }
]

Es importante recordar que los datos se almacenan únicamente en memoria. Si el servidor se reinicia o se apaga, todos los reportes registrados se perderán porque todavía no se está utilizando una base de datos.

reflexion-semana7.txt
Las plataformas tecnológicas son herramientas muy importantes para que las comunidades puedan registrar y consultar reportes o incidencias de manera organizada. Gracias a estos sistemas, los ciudadanos pueden informar problemas relacionados con infraestructura, seguridad, medio ambiente o servicios públicos de forma rápida y sencilla. Además, permiten mantener un historial de los reportes realizados y facilitan el seguimiento de cada situación. La información recopilada ayuda a las autoridades a identificar necesidades prioritarias y tomar mejores decisiones. También promueve la participación ciudadana, ya que las personas pueden involucrarse activamente en la mejora de su entorno. Otro beneficio es que la información puede consultarse en cualquier momento y desde diferentes dispositivos. Esto mejora la comunicación entre la comunidad y las entidades responsables. En conclusión, una plataforma de reportes contribuye al desarrollo de comunidades más organizadas, participativas y eficientes en la solución de problemas.
